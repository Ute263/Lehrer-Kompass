# Fächer und Klassen-Fach-Zuordnungen

Die zehn Systemfächer sind stabile `SubjectDefinition`-Datensätze: Deutsch, Mathematik, Sachunterricht, Kunst, Musik, Sport, Religion, Englisch, Förderunterricht und Weitere Fächer. `ClassSubject` aktiviert, deaktiviert und ordnet ein Fach je Klasse.

Deaktivieren löscht weder Zuordnung noch Themen. Themen können erst wieder angelegt werden, wenn das Fach aktiv ist. Die Klassenansicht bietet zugängliche Auf-/Ab-Aktionen; ihre Reihenfolge wird lokal gespeichert.
