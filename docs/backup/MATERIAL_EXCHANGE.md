# Materialaustausch
`.lehrerkompass-material.json` enthält Material, Dokument, Seiten, Blöcke und Lösungen. Rechteinformationen bleiben erhalten. Import erzeugt neue IDs und weist Skripte, `javascript:` sowie externe OneDrive-/Dateipfade ab. Die Service-API ist implementiert; eine vollständige Material-Exportoberfläche folgt.
