# Wiederherstellungspunkte
Dexie v7 speichert maximal fünf lokale JSON-Snapshots vor Import, Reset oder Wiederherstellung. Angezeigt werden Zeitpunkt, Grund und Schätzgröße. Älteste Punkte werden kontrolliert entfernt. Sie liegen ausschließlich auf diesem Gerät und ersetzen keine externe Sicherung.
