# KI-Buddy – Überblick

Der KI-Buddy ist eine kontrollierte Vorschlagswerkstatt innerhalb des bestehenden AppShell-Drawers. Er unterstützt Unterrichtsstunden, Reihendurchführungen und Materialien, verändert aber niemals beim Generieren Fachdaten.

Der Ablauf ist verbindlich: Ziel erkennen, Fähigkeit wählen, Kontextvorschau prüfen, Vorschlag bewusst starten, strukturierte Änderungen vergleichen, Änderungen einzeln auswählen und erst dann über vorhandene Domainservices übernehmen. Vor einer fachlichen Änderung entsteht eine lokale Version. Ein Rollback stellt den vorherigen Stand wieder her.

Paket 09 läuft vollständig im lokalen Mock-Modus. Der echte OpenAI-Betrieb ist ausschließlich über einen späteren vertrauenswürdigen Serveradapter vorbereitet.
