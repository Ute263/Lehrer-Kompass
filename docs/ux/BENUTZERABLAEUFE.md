# Benutzerabläufe

## Grundprinzip
Immer nur ein Hauptarbeitsplatz, klare nächste Handlung, Autosave, jederzeit abbrechen und später fortsetzen. Bekannte Daten werden nicht erneut abgefragt.

## Neue Reihe
Werkbank → Neue Unterrichtsreihe → Klasse/Fach/Thema → Lehrwerk/Arbeitsplan/frühere Reihe auswählen → Rahmendaten → Quellen bestätigen → Grundgerüst selbst, aus Vorlage oder mit Buddy → Vorschlag prüfen → Stammreihe und Durchführung anlegen → Werkbankeintrag.

## Frühere Reihe übernehmen
Reihe öffnen → Für neue Klasse übernehmen → Schuljahr/Klasse/Zeitraum → Übernahmeumfang → Abgleich mit aktuellem Lehrwerk und Vorgaben → Unterschiede/Reflexionen prüfen → neue Durchführung anlegen. Frühere Durchführung bleibt unverändert.

## Grundplanung
Grundlagen → Lernvoraussetzungen → Ziele/Kompetenzen → Inhaltsbausteine → Stundenfolge → Zeitrahmen → Differenzierung → Leistungsüberprüfung → Qualitätscheck.

## Stunde planen
Stunde öffnen → Schnell- oder ausführliche Planung → Grundlagen übernehmen → Lernziel → Phasen → Zeit prüfen → Differenzierung → Material → Vorbereitung → Qualitätscheck → einsatzbereit markieren.

## Terminierung
Stunde oder Reihe → passende Slots aus festem Stundenplan → Vorschau → bestätigen. Bei Ausfall: Historie behalten, neu terminieren, unterminiert lassen, zusammenführen oder entfallen lassen.

## Arbeitsblatt
Aus Stunde/Materialwerkstatt → Materialart und Kontext → Umfang/Niveau/Aufgaben/Gestaltung/Lösungen → Quellen wählen → strukturiert generieren → tatsächliche Vorschau → Aufgaben und Arbeitsflächen bearbeiten → Qualität prüfen → PDF/DOCX → OneDrive-Ziel → mit Stunde verknüpfen.

## Bibliotheksmaterial verwenden
Material öffnen → Vorschau/Bewertung/Speicherort → Original verknüpfen, Kopie/Variante erstellen, einzelne Aufgaben übernehmen oder nur als Quelle nutzen → Ziel auswählen.

## Förderreihe
Fördergruppe/Kind → Ausgangslage → Förderziel → Zeitraum → Einheiten strukturieren → Material → Terminierung → Durchführung und Kurzreflexion. Sensible Daten bleiben anonymisiert.

## Reflexion
Nach Durchführung → kurze Gesamteinschätzung → Kategorien/Notiz → optional nächste Stunde oder Material anpassen → langfristige Erfahrung nur nach Bestätigung.

## Reihe abschließen
Vollständigkeit und tatsächliche Dauer prüfen → Reihenreflexion → bewusst auswählen, was in die Stammreihe übernommen wird → Durchführung abschließen → von Werkbank nehmen.

## Tages-/Vertretungsübersicht
Datum → Unterrichtstermine → vorhandene Ziele, Abläufe, Seiten und Materialien übernehmen → persönliche oder datenschutzgefilterte Vertretungsansicht → fehlende Angaben ergänzen → PDF/DOCX/OneDrive-Freigabe.

## Unterbrechen
Aktuellen Ort, geöffneten Abschnitt, Entwürfe und Scrollposition lokal sichern. Beim nächsten Öffnen genau dort „Weiterarbeiten“ anbieten.
