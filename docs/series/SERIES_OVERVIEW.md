# Unterrichtsreihen

Paket 05 erweitert den Pfad `Klasse → Fach → Thema → Unterrichtsreihe`. Eine `SeriesTemplate` ist das wiederverwendbare fachliche Grundobjekt. Jede `SeriesImplementation` ist eine neue konkrete Nutzung für Klasse und Schuljahr. Grundplanung, Gliederung und Werkbankreferenz gehören ausschließlich zur Durchführung beziehungsweise verweisen auf sie.

Nicht enthalten sind vollständige Unterrichtsstunden, Phasen, Materialien, Termine, Backend, OneDrive oder KI.
