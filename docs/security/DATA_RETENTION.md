# Datenschutz und Aufbewahrung

Gespeichert werden minimierte Providerkennung, Anzeigename, privater Workspace, Fachdaten, widerrufbare Sitzungen, Buddy-Metadaten und sparsame Auditereignisse. Sitzungen enden nach Ablauf/Logout; Buddyverlauf soll nutzerbezogen archivier- oder löschbar sein. Workspace-Deaktivierung ist vorbereitet. Vollständige irreversible Löschung bleibt bis zu einem geprüften Löschjob blockiert. Export darf nur den eigenen Workspace umfassen.
