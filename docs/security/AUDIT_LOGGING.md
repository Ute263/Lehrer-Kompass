# Audit

Audit speichert Workspace, Akteur, Aktion, Zielkennung, Ergebnis und Zeitpunkt. Erfasst werden Login, Logout, Importvorschau/-commit, Ressourcenänderung/-archivierung, Buddy-Anfrage und verweigerter Zugriff. Volltexte, Prompts, Unterrichtsinhalte, Tokens, Secrets und Providerantworten sind ausgeschlossen.
