# LehrerKompass – Arbeiten mit dem iPad

GitHub bleibt die verbindliche Quelle. ZIP-Downloads, Entpacken und manuelles Wiederhochladen sind kein Standardworkflow.

## Fester Ablauf

1. Änderung in der ChatGPT-App beauftragen.
2. Repository `Ute263/Lehrer-Kompass` und das aktuelle Paket eindeutig nennen.
3. Änderungen in einem eigenen Branch ausführen.
4. Pull Request mit Cloudflare-Vorschau erstellen.
5. Vorschau auf dem iPad in Safari prüfen.
6. Fehler mit Screenshot und genauer Beobachtung melden.
7. Erst nach Abnahme in `main` zusammenführen.

## Dateien auf dem iPad

- Sicherungen sowie Reihen- und Materialexporte werden über die Dateien-App gespeichert.
- Safari kann je nach Version statt eines Speicherortdialogs einen Download erzeugen. Die Datei liegt dann im Ordner „Downloads“ der Dateien-App.
- Importdateien werden über „Datei auswählen“ aus der Dateien-App geöffnet.
- Vor größeren Änderungen und vor dem Löschen von Browserdaten immer eine vollständige Sicherung erstellen.

## Installation

In Safari: Teilen → Zum Home-Bildschirm. Die Installation ist freiwillig. Lokale Daten liegen weiterhin auf dem jeweiligen Gerät.

## Reale Abnahme

Gerätetests gelten erst als bestanden, wenn sie tatsächlich auf dem iPad durchgeführt und im Abschlussbericht dokumentiert wurden. Automatische Tests ersetzen diese Prüfung nicht.
