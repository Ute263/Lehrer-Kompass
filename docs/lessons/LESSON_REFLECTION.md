# Stundenreflexion

Die optionale Reflexion wird getrennt von Planung und Stunde gespeichert. Sie hält Gelungenes, Änderungsbedarf, tatsächliche Dauer und den nächsten fachlichen Schritt fest. Beim Duplizieren einer Stunde wird sie bewusst nicht kopiert, damit keine Durchführungserfahrung als neue Beobachtung erscheint.
