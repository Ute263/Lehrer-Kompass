# Unterrichtsstunden

Eine Unterrichtsstunde ist ein eigenständiger lokaler Arbeitsplatz unter einer konkreten Reihendurchführung. Ein Punkt der Stundenfolge kann optional genau eine echte Stunde referenzieren; die Gliederung bleibt dabei unverändert erhalten. Stunden können außerdem unabhängig ergänzt, sortiert, dupliziert, abgesagt oder archiviert werden.

Die Route `/stunden/:lessonId` zeigt Kontext, Planungsstand, Ablauf, Zeitbilanz, Reflexion und Werkbankstatus. Kalendertermine und Materialdateien sind ausdrücklich nicht Teil dieses Pakets.
