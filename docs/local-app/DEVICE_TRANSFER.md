# Gerätewechsel
Gerät A: Sicherung erstellen und über den normalen Dateidialog an einem selbst gewählten Ort ablegen. Gerät B: App öffnen/installieren, Datei auswählen, Vorschau prüfen und bewusst importieren. Danach arbeiten beide Geräte unabhängig. Änderungen auf verschiedenen Geräten werden nicht automatisch zusammengeführt; für einen neuen Stand ist ein erneuter Export/Import nötig.
