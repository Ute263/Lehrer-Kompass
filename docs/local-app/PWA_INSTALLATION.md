# PWA-Installation
Geprüft am 15.07.2026. Chromium-basierte Browser können eine installierbare Web-App aus Manifest und Service Worker anbieten; die Installation bleibt freiwillig. Auf iPadOS beschreibt Apple den Weg Safari → Teilen → Mehr → „Zum Home-Bildschirm“ → „Als Web-App öffnen“ ([Apple Support](https://support.apple.com/de-de/guide/ipad/ipad8f1f7a29/ipados)). Reale Geräteprüfung: Desktop vorbereitet/manuell im Browser geprüft; iPad nur anhand offizieller Dokumentation vorbereitet, nicht real geprüft.

Privater Browsermodus wird wegen nicht verlässlich dauerhafter lokaler Speicherung nicht empfohlen. Browserdaten oder das Entfernen der App können lokale Daten löschen.
