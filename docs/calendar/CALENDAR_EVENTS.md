# Kalendereinträge

Kalendereinträge können auf eine Unterrichtsstunde verweisen, müssen es aber nicht. Unterstützt werden Unterricht, schulische Sondertermine, Lernzielkontrollen und schulische Organisation. Private Termine werden fachlich nicht angeboten.

Verschieben archiviert den historischen Ausgangstermin als `moved` und erzeugt transaktional einen neuen, auf ihn verweisenden Termin. Ausfall und Durchführung ändern zunächst nur den Termin. Eine zugehörige Stunde wird ausschließlich nach eigener Bestätigung und über einen gültigen Statusübergang abgeschlossen.
