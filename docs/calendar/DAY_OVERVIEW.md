# Tagesübersicht

Die Tagesübersicht wird aus Kalender-, Stunden-, Planungs- und Phasendaten abgeleitet. Sie zeigt nur vorhandene Angaben: Zeit, Klasse, Fach, Thema, Lernziel, Phasenüberblick, Materialbedarf, Vorbereitung, Hausaufgabe und organisatorische Hinweise. Sie erzeugt keine fehlenden Inhalte und wird nicht als Datei exportiert.
