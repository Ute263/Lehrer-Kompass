# Materialfamilien und Varianten

Eine Variante ist eine eigenständige tiefe Kopie innerhalb derselben Familie. Material, Dokument, Seiten, Blöcke und Lösungen erhalten neue IDs; Lösungen starten ungeprüft. Das Ausgangsmaterial bleibt unverändert und wird vor der Kopie versioniert.

Neutrale sichtbare Variantennamen sind von internen Variantentypen getrennt. Dadurch entstehen keine personenbezogenen oder stigmatisierenden Bezeichnungen.
