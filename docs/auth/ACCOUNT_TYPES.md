# Kontotypen

Interne Typen sind `personal` und `work_school`. Version 1 gibt persönliche Microsoft-Konten frei. Arbeits-/Schulkonten sind architektonisch vorbereitet, aber nicht zugesagt. Subject und validierter Issuer/Audience bilden die Identität; gleiche E-Mail-Adressen werden nie zusammengeführt.
