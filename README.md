# LehrerKompass
## The Quiet Workspace

LehrerKompass ist ein privater, ruhiger digitaler Arbeitsplatz zur Planung, Durchführung und Weiterentwicklung von Unterricht.

Das Repository befindet sich aktuell in der **Vorbereitungs- und Machbarkeitsphase**. Es enthält noch keine produktive App. Der erste Entwicklungsauftrag prüft ausschließlich die technisch riskanten Bereiche OneDrive, Dokumentexport, Offline/Autosave, strukturierte KI-Ausgaben sowie Bibliothekssuche.
